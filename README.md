# Manual Web Application Testing – SauceDemo

## Project Overview

This project demonstrates a manual testing process for the SauceDemo web application.

The project covers test planning, test scenario design, test case design, test execution, and test result reporting.

## Application Under Test

**Application:** SauceDemo  
**Testing Type:** Manual Web Application Testing  
**Platform:** Desktop Web  
**Browser:** Firefox  
**Operating System:** Windows

## Testing Scope

The following functional areas were tested:

- Login: 7
- Product Listing: 7
- Product Sorting: 3
- Product Details: 8
- Shopping Cart: 10
- Checkout: 10
- Logout: 5

## Test Artifacts

| Artifact | Description |
|---|---|
| Test Plan | Defines the testing scope, objectives, environment, and criteria |
| Test Scenarios | Defines the high-level scenarios covered by testing |
| Test Cases | Defines detailed test steps and expected results |
| Bug Reports | Used to document identified defects |
| Test Summary Report | Summarizes test execution and results |

The project followed this testing workflow:

**Test Plan → Test Scenarios → Test Cases → Test Execution → Test Results → Test Summary Report**
