
# Manual Web Application Testing

## Project Overview

This project demonstrates a practical manual software testing process
for a web application.

The project covers:

- Test planning
- Test case design
- Functional testing
- Positive and negative testing
- Boundary value analysis
- Bug reporting
- Regression testing
- Test reporting

## Testing Scope

The application will be tested from a functional and user perspective.

## Testing Types

- Functional Testing
- UI Testing
- Negative Testing
- Boundary Value Testing
- Regression Testing
