# Test Plan

## 1. Scope

### Login
- Valid login
- Invalid login
- Empty fields

### Product Listing
- Display products

### Product Sorting
- Sort products

### Product Details
- View product details

### Shopping Cart
- Add item
- Multiple quantity of the same product
- Remove item
- Cart contents

### Checkout
- Customer information
- Order summary
- Complete order

### Logout


## 2. Objective

The objective of this testing project is to verify that the main functional features of the web application work as expected and to identify and document any defects found during testing.


## 3. Out of Scope

The following areas are outside the scope of this project:

- API testing
- Performance testing
- Security testing
- Database testing
- Mobile application testing
- Test automation
- Accessibility testing


## 4. Test Types

- Functional Testing
- Positive Testing
- Negative Testing
- UI Testing
- Boundary Value Testing
- Regression Testing


## 5. Test Environment

- Application: SauceDemo
- Environment: Web browser on desktop
- Operating System: Windows
- Browser: Firefox Version 156.0.1 (64-bit)


## 7. Entry Criteria

Testing can begin when:

- The application is accessible.
- The required test account is available.
- The main features in scope are available for testing.

## 8. Exit Criteria

Testing can be completed when:

- All planned test cases have been executed.
- All identified defects have been documented.
- Test results have been recorded.
- A Test Summary Report has been prepared.
